# OpenAtlas plugin

Follow `open-ecosystem/OPERATING-STANCE.md`. Start the first real tool in this turn.

OpenBrain loads `OpenBrainIntegration/OpenAtlas/openbrain.plugin.json`. Tools are `atlas_*`.

Start with `atlas_status`. Create a profile (`qa-lab` / `privacy-ninja` / `daily` / `automation`). Apply privacy and proxy while **stopped**. Confirm, then `atlas_profile_start`. Run bounded jobs. Stop the session.

Do not use Atlas Team, license, or Atlas AI-provider tools — they are not in this plugin. Do not confuse with Playwright MCP on :3100 or Obscura CDP.
